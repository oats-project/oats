# Reference screens

A live prototype of the bb extension:
https://octolens.dsp.so/iIl0jTlJ-oats-in-bb-the-end-state-live

It was made before this skill, when the product was called OATS. Read "OATS" in it as "aweb". Its colours are its own: ignore them. The look is bb's, from theme tokens. It is mostly click-first: don't copy that. The prototype as a whole is not approved. These elements are:

1. **The dock**, bottom right: "Talk to aweb agent". The main call on every page.
2. **The sidebar**: a quiet "aweb" heading with the workspace name. Automations and Workspace on top. Then the agents.
3. **The agent row**: the name, then a one-colour harness mark and the soul's label. One dot. No state word.
4. **The collapsed parent**: the number of agents under it. It changes colour when one of them needs you.
5. **The "needs you" line** in a thread, with its answer on the same line.
6. **New agent**: the host's own composer, with a soul picker that filters as you type.
7. **An agent's side panel**: Info with lineage, Board, Mail.
8. **Workspace**: souls and capabilities as aligned rows. A soul's page with tabs. Long text in a sheet on the right.
9. **Automations**: one row per automation. A run opens its agent's thread.
10. **Onboarding**: four steps. Workspace, This computer, Team, First agent.
11. **The workspace name** opens a workspace switcher.
12. **Keys**: Alt Down and Alt Up for the next and previous agent. Alt J for the aweb agent.

Changed since the prototype:
- Talking to an agent is thread-based: many threads with one agent.
- Every agent has a command to switch to its terminal view.
- Every colour, radius and font comes from bb's theme tokens.
