# How Claude Code asks for input

The model for "needs you". Written from using Claude Code, not from its source.

## A permission

- It shows what the agent wants to do: the tool and the exact command or change.
- Under it, a short numbered list:
  1. Yes
  2. Yes, and don't ask again for this
  3. No, and tell the agent what to do instead
- Up and Down move. A digit picks. Enter confirms. Esc says no.
- What led to the request is right above it, in the same view.

## A question

- The question, in one line.
- Two to four choices, each a short label with one line under it.
- Always a way to type something else.
- Same keys.

## What to take

1. The request and its context are in one place. You don't go looking.
2. The choices are few, numbered, and named by what they do.
3. Every choice has a key. The pointer works too.
4. There is always a way to say something else.
5. Nothing is selected in a way that sends by accident.
