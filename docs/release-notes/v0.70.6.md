# OATS 0.70.6

Unreleased

A patch release of two Desktop fixes: the Needs input mark on a terminal
tab shows whole again, and the status line names this computer by the
sidebar's rule.

## Upgrade

- **The Desktop and the CLI** can be upgraded in either order. Both fixes
  are in the Desktop.
- **The pi bridge** (`@awebai/oats-pi` 0.70.6) reaches each pi folder with
  `oats update`. It is unchanged apart from its version.

## Fixed

- **The Desktop's status line shows this computer's name by the same rule
  as the sidebar.** A host name with a line break now shows on one line,
  an unprintable character as �, and a name with a terminal control
  character or a secret-like value shows nothing, as the sidebar already
  did for another machine's name
  ([#2095](https://github.com/oats-project/oats/issues/2095)).

- **The Desktop's Needs input mark shows whole on a terminal tab.** Since
  the tab's status dot moved after the name, the alert glyph that replaces
  it while an agent waits on you lost its right edge whenever it ended the
  tab's line: a long name with no branch, or a tab at its narrowest. The
  mark now has a 12px slot whichever state it shows, with the dot centred in
  it, so the glyph is never clipped and the name does not move when an agent
  starts or stops waiting. Terminal tabs are 5px wider at their narrowest
  (181px) to keep the room the name had; other tabs are unchanged.
