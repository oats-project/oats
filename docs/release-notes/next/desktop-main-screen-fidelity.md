## Changed

- **The Desktop's main screen now looks like the redesign's prototype**
  (the Desktop UI rework, slice 3d). This changes the look only: no key, no
  behaviour and no contract changes. Colours stay on the theme: on an Omarchy
  computer the default is still Omarchy's own colours.
  - **The sidebar:**
    - **WORKSPACES** and **AGENTS** are small capitals headings;
    - each agent is two compact lines: its name, then its soul and machine,
      smaller and muted;
    - "new" is a small pill;
    - **Automations** says "1 failed" in red after its name while a
      schedule's last run failed, instead of a red dot;
    - **?** at the foot is a quiet round button;
    - there is no line between the pinned rows and the agents.
  - **Tabs** are small pills, 28px tall in a 44px bar. The active one is
    filled and its number is in the accent colour.
  - **The agent view:** each fact is a strip of its own, with its time at the
    right. The question is a card: "needs you", the question, then its options
    as boxed rows, each with its number.
  - **The status line** at the bottom is a quieter 28px key bar: the keys in
    the window's own type, with a small dot between two.
  - **The sheets** (Appearance, Keyboard shortcuts, an agent's mail, the
    leader's help sheet) have the prototype's titles, small uppercase section
    headings and spacing.
