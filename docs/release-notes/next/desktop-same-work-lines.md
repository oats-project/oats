## Changed

- **The Desktop's sidebar draws lines again, where work is shared.** A solid line joins a parent to a child whose host reports it doing the same work as its parent, as the sidebar drew it before its rework, and a screen reader hears "related work" after "under <parent>". Any other child is indented with no line, and so is every child on a host whose OATS doesn't report shared work. Siblings get no line yet. The command palette's lines don't change.
