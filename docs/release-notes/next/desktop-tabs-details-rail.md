## Added

- **Every page is a tab in the Desktop.** Home, the Workspace page, Automations and an agent's Details open as tabs beside the terminals, brains and files. Splits take any tab, so Home can sit beside a terminal. A new pane opens Home as its first tab. Each workspace keeps its page tabs, and they come back when the workspace shows again.
- **Details for any agent.** `i` on a row, ⌘I / Ctrl+Shift+I, **Details** in the row's menu or the palette's **Agent: Details** opens an agent's Details tab, running or stopped. It holds what the instance panel showed: the agent's work, session, lineage, messaging and teams, Needs input, its soul, and its Git state and pull request, with Start, Stop and Retire. A keyboard-only user can now read a stopped agent's repository, branch, harness and model.
- **The sidebar's rail.** ⌘B / Ctrl+Shift+B collapses the sidebar to a narrow rail and back: the pinned destinations, then one dot per agent in the roster's order with its needs-input mark, and the "need you" count. **Sidebar: hide** in the palette still hides it entirely.

## Changed

- **Home follows the roster in any pane**, with the sidebar collapsed or hidden. **Home › Agents** puts pinned agents first, as the roster does.
- **A terminal tab no longer opens the instance panel beside it.** Its agent's Details is one key away.
- **With no tab open**, the main area offers **Open Home** in place of a page behind the tabs.
