## Documentation

- **[The trust model](../trust-model.md) says who OATS trusts with what.**
  Everything that runs as one operating-system user is one trust group, the
  kernel included. The page gives the five rules that follow, what OATS does
  not promise inside a group, and which keys are held outside it.
  [The team container](../container.md#one-team-one-trust-group) now states
  in full that a container is the unit of compromise and holds one team.
