## Changed

- **Desktop: Home shows what needs you, and the Workspace page has its own row and a way back.**
  ([Workspaces](../desktop.md#workspaces))
  - **Home is one centred column.** **Needs you** comes first: each agent waiting on you, with its
    soul, its machine and its message, newest first. Eight show at most, then **Show all N**. With
    none, "Nothing needs you."
  - **One summary line** counts the rest: "24 agents · 21 running · 3 need you · 0 stopped".
  - **The workspace is one row of tiles**, each a button with its count: Agents, Souls,
    Capabilities, Teams, Machines and Automations (with the red dot while a run failed). They show
    without scrolling, even with eight agents waiting on you. The Graph tile is gone; Machines keeps
    its List and Map.
  - **Running**, under the tiles, shows five running agents, then **Show all N running**. No row
    says "running" any more: the heading does.
  - **The sidebar's pinned rows are Home, Workspace and Automations.** Opening any Workspace page
    (from a tile, the command palette, ⌘2 / Ctrl+2, or a soul's or capability's page) marks the
    Workspace row, no longer Home's. Its palette command is now **View: Workspace**.
  - **Every Workspace page says where you are, and the way back:** **Home › Workspace › Souls**
    above the tabs, and **Home › Workspace › Souls › dev** on a soul's page, each part a link. Esc
    goes up one level: twice from a soul's page reaches Home.
  - **Capabilities shows the Workspace defaults again**, above the list: the Core slots (Knowledge,
    Messaging, Tasks) and the Additional defaults, each as the list's own row.
  - **Soul cards read more clearly:** the name larger and bolder, what the soul does in muted body
    text, its agents and kind on a smaller line.
