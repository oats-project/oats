## Changed

- **The Desktop's sidebar reads more calmly.** An agent's row is two lines: its name, then its soul and the machine it runs on ("oats-expert · falcon": this computer's own rows by its `host.name` in `oats-local.yaml`, else "This Mac"), in a 44px row with its dot centred. The repository, branch, pull request and harness badge are no longer on the row, and the row has no hover card and no tools on hover: the instance panel shows the repository, branch, harness and model, and a new **Needs input** section with the reason an agent waits, how long it has waited and its message; the row's context menu (right-click, Shift+F10 or the Menu key) opens its pull request (**Open pull request…**) and starts a stopped agent (**Start…**). Until the panel serves an agent whose terminal isn't open, the row's tooltip says its repository, branch, harness and model; with the keyboard alone those show once its terminal is open. The roster draws no lines between agents any more: a child is indented under its parent, a little space separates each group from the next, and a screen reader hears "under <parent>" (with "same work" for a child doing its parent's work) and "sibling of <name>". The order and the needs-input marks are unchanged, and the command palette keeps its lines. **Workspace overview** and **Automations** are pinned rows under the list of workspaces, and **Automations** shows a red dot, which a screen reader hears as "a run failed", while a schedule's last run failed. The foot shows **N need you** (it takes you to the first agent that needs you), **New agent** and **?** (the keyboard shortcuts). An empty roster says "No agents yet" and the key that starts one. The CLI and the docs still say "instance". See [the sidebar](../desktop.md#workspaces) and [its instance tree](../desktop.md#the-sidebars-instance-tree).

## Removed

- **Show only the current workspace.** The list of workspaces always shows every workspace: the toggle, its ⌥⇧⌘O / Ctrl+Alt+Shift+O (which reaches a terminal's program again) and its palette command are gone, and a choice saved for it is ignored.
- **The sidebar's settings cog, its Hide sidebar button and its brand mark.** Theme, font and keyboard shortcuts are in the command palette (**Theme: choose…**, **Font: choose…**, **Shortcuts: edit keyboard shortcuts…**) and on the foot's **?**; the sidebar still hides with ⌘B / Ctrl+Shift+B, the palette's **Sidebar: toggle (hide/show)** and **Show sidebar**.
