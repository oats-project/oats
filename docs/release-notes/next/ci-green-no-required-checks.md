## Changed

- **"CI green" in OATS's landing rules no longer holds with every check red.** The rules defined it as every check the forge requires at a head having succeeded. OATS's repositories require no check on their default branches, so that definition was empty. Where the forge requires no check, CI green at a head now means at least one check ran there, every check that ran succeeded, and none is failing or pending. A head where no check ran isn't green. Every skill that reads "CI green" (a developer's "Ready", a maintainer's read and merge, a release's source) takes it from the landing rules, so they change with it. A running instance takes the change up as the landing rules say a change reaches one: whoever lands it tells each standing instance and each open effort's lead, at its commit, and each records it in its state file. A respawn picks it up too.
