## Fixed

- **The getting-started skill reads a failed join from what ran.** Its last messaging check (step 9, item 5) no longer says a run left the root outside the team when no root was made. After the signup or the labelled join it says no root was made or recorded, and a team create that recorded no root is rerun unchanged. Before the person's join window opens, the agent lists the per-team roots and compares the list afterwards, so a root from an earlier join is not read as this one. It compares the team's label as the provider writes the folder name: lowercase, `_` and `.` as `-`. When the window shows no `E_SETUP_` code, the agent asks for the window's last line. The agent still never sees the join's output, never reruns it, and asks for no secret ([#1746](https://github.com/oats-project/oats/issues/1746)).
